MNIST Digit Recognition Dashboard - Cloud Deployment

Files required in the GitHub repository root:
- app.py
- model.py
- mnist_cnn.pth
- app_icon.png
- requirements.txt

Deployment target: Streamlit Community Cloud
Main file: app.py
Recommended Python version: 3.11

Do not upload __pycache__ or .pyc files.
The model weights file mnist_cnn.pth must remain in the same folder as app.py.
